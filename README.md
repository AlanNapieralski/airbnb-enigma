# airbnb-enigma
The complicated Airbnb accommodation price-splitting problem that I decided to solve programmaticaly for my friends

<!-- ABOUT THE PROJECT -->
## About The Project
After a holiday trip with friends turned into an Excel nightmare and Splitwise let us down, we decided to build our own solutions for splitting expenses. My contribution, airbnb-enigma project, is a simple, home-grown algorithm that calculates exactly who owes what — no more confusion, no more manual math.

It all started with one question: “Why is this so hard?”
So we built a lightweight tool that takes into account different contributions and shares, and spits out exactly who pays whom, and how much — down to the penny.

No app store. No ads. Just code, friends, and clean debt-settling.
